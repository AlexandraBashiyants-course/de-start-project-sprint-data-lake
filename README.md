# Data Lake — Социальная сеть (Австралия)
из-за частых ошибок 137 очень сильно сократила данные
## Структура HDFS

Данные организованы по принципу зонирования:

- `/user/master/data/sprint_3/raw` — сырые данные (необработанные).
- `/user/master/data/sprint_3/staging` — промежуточные таблицы для тестирования.
- `/user/master/data/sprint_3/marts` — финальные витрины данных для аналитиков.
- `/user/master/data/sprint_3/geo` — справочник геоданных (городов).

## Источники данных

- События (сообщения, реакции, подписки):  
  Путь: `/user/master/data/geo/events`  
  Формат: Parquet  
  Обновление: каждый час (streaming или batch)

- Справочник городов Австралии (`geo.csv`):  
  Путь: `/user/master/data/sprint_3/geo/cities`  
  Формат: CSV  
  Обновление: редко (вручную при расширении)

## Витрины

| Витрина | Назначение | Обновление |
|--------|-----------|------------|
| `user_geo_mart` | Профиль пользователя: дом, актуальный город, путешествия | Ежедневно |
| `zone_geo_mart` | Аналитика событий по городам | Еженедельно (с накоплением месячных) |
| `friend_recommendations` | Пары пользователей для рекомендации друзей | Ежедневно |

## Формат хранения

Все витрины хранятся в формате **Parquet** — эффективный бинарный формат для больших данных.

## Инструменты

- PySpark (для обработки данных)
- Apache Airflow (оркестрация DAG)

- Jupyter Notebook (отладка)
