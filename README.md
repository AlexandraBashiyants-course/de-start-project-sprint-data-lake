# Spark Data Mart Project

Этот проект реализует построение аналитических витрин (data marts) на основе событий пользователей в геолокационной системе.

## Структура проекта

- `user_mart_builder.py` — строит витрину пользователя с актуальным городом, домашним городом и историей перемещений.
- `zone_mart_builder.py` — строит витрину зон активности пользователей.
- `friend_recommendation_mart_builder.py` — формирует рекомендации друзей на основе подписок и близости.
- `run_*.py` — скрипты запуска соответствующих витрин.
- DAG в Airflow — orchestration всех задач.

## Важное примечание: работа с ограниченными ресурсами

При работе на учебном кластере Yandex Cloud Dataproc возникла проблема:

> **Контейнеры падали с `exit code 137` (OOM — Out of Memory)** из-за ограничений среды:
> - Кластер автоматически выставляет `spark.driver.cores=6`
> - Невозможно эффективно контролировать `memoryOverhead`
> - Даже минимальные операции приводили к нехватке памяти

### Решение

Чтобы гарантировать выполнение задач, **объём данных был сильно уменьшен**:

- Чтение только одной даты: `/date=2022-05-01`
- Фильтрация через `.sample(0.01)` и `.limit(N)`
- Использование `.repartition(1)` для минимизации shuffle
- Отказ от тяжёлых операций до подтверждения работоспособности

messages = messages.sample(0.01, seed=42).limit(10)
